    32→## ⚡ Quick Start
    33→
    34→### Option 1: Install the app (Recommended)
    35→
    36→The fastest way in — no clone, no terminal. [**Agency Agents**](https://agencyagents.app) is a native desktop app (macOS · Linux · Windows) that browses the whole roster and installs agents into Claude Code, Cursor, Codex, Gemini CLI, OpenCode, Qwen, and Osaurus for you, then keeps them up to date.
    37→
    38→**[⬇ Download the latest release](https://github.com/msitarzewski/agency-agents-app/releases/latest)** — or on a Mac:
    39→
    40→```bash
    41→brew install --cask msitarzewski/agency-agents/agency-agents
    42→```
    43→
    44→Prefer the command line? The script-based options below install the same agents.
    45→
    46→### Option 2: Use with Claude Code
    47→
    48→```bash
    49→# Install all agents to your Claude Code directory
    50→./scripts/install.sh --tool claude-code
    51→
    52→# Or manually copy a category if you only want one division
    53→cp engineering/*.md ~/.claude/agents/
    54→
    55→# Then activate any agent in your Claude Code sessions:
    56→# "Hey Claude, activate Frontend Developer mode and help me build a React component"
    57→```
    58→
    59→### Option 3: Use as Reference
    60→
    61→Each agent file contains:
    62→- Identity & personality traits
    63→- Core mission & workflows
    64→- Technical deliverables with code examples
    65→- Success metrics & communication style
    66→
    67→Browse the agents below and copy/adapt the ones you need!
    68→
    69→### Option 4: Use with Other Tools (GitHub Copilot, Antigravity, Gemini CLI, OpenCode, OpenClaw, Cursor, Aider, Windsurf, Kimi Code, Codex, Osaurus, Hermes, Mistral Vibe)
    70→
    71→```bash
    72→# Step 1 -- generate integration files for all supported tools
    73→./scripts/convert.sh
    74→
    75→# Step 2 -- install interactively (auto-detects what you have installed)
    76→./scripts/install.sh
    77→
    78→# Or target a specific tool directly
    79→./scripts/install.sh --tool antigravity
    80→./scripts/install.sh --tool gemini-cli
    81→./scripts/install.sh --tool opencode
    82→./scripts/install.sh --tool copilot
    83→./scripts/install.sh --tool openclaw
    84→./scripts/install.sh --tool cursor
    85→./scripts/install.sh --tool aider
    86→./scripts/install.sh --tool windsurf
    87→./scripts/install.sh --tool kimi
    88→./scripts/install.sh --tool codex
    89→./scripts/install.sh --tool osaurus
    90→./scripts/install.sh --tool hermes
    91→./scripts/install.sh --tool vibe
    92→```
    93→
    94→**Install only the teams you need** (not everyone wants every division):
    95→
    96→```bash
    97→./scripts/install.sh                                    # interactive wizard: pick tools + teams
    98→./scripts/install.sh --tool claude-code --division engineering,security
    99→./scripts/install.sh --tool cursor --agent frontend-developer,ui-designer
   100→./scripts/install.sh --list teams                       # see every team + agent count
   101→./scripts/install.sh --tool opencode --division engineering --dry-run
   102→```
   103→
   104→> **OpenCode note:** OpenCode's runtime currently registers only ~119 agents and silently drops the rest ([upstream bug](https://github.com/anomalyco/opencode/issues/27988)). Installing a subset with `--division` keeps you under that limit. The installer warns you when a selection would exceed it.

   733→- **[Qwen Code](https://github.com/QwenLM/qwen-code)** — `.md` SubAgent files → `~/.qwen/agents/`
   734→- **[Kimi Code](https://github.com/MoonshotAI/kimi-cli)** — YAML agent specs → `~/.config/kimi/agents/`
   735→- **[Codex](https://developers.openai.com/codex/overview)** — TOML custom agents → `~/.codex/agents/`
   736→- **Osaurus** -- `SKILL.md` skills -> `~/.osaurus/skills/`
   737→- **[Hermes](integrations/hermes/README.md)** -- lazy-router plugin -> `~/.hermes/plugins/`

   741→### ⚡ Quick Install
   742→
   743→**Step 1 -- Generate integration files:**
   744→```bash
   745→./scripts/convert.sh
   746→# Faster (parallel, output order may vary): ./scripts/convert.sh --parallel
   747→```
   748→
   749→**Step 2 -- Install (interactive, auto-detects your tools):**
   750→```bash
   751→./scripts/install.sh
   752→# Faster (parallel, output order may vary): ./scripts/install.sh --no-interactive --parallel
   753→```
   754→
   755→The installer scans your system for installed tools, shows a checkbox UI, and lets you pick exactly what to install:
   756→
   757→```
   758→  +------------------------------------------------+
   759→  |   The Agency -- Tool Installer                 |
   760→  +------------------------------------------------+
   761→
   762→  System scan: [*] = detected on this machine
   763→
   764→  [x]  1)  [*]  Claude Code     (claude.ai/code)
   765→  [x]  2)  [*]  Copilot         (~/.github + ~/.copilot)
   766→  [x]  3)  [*]  Antigravity     (~/.gemini/antigravity)
   767→  [ ]  4)  [ ]  Gemini CLI      (~/.gemini/agents)
   768→  [ ]  5)  [ ]  OpenCode        (opencode.ai)
   769→  [ ]  6)  [ ]  OpenClaw        (~/.openclaw/agency-agents)
   770→  [x]  7)  [*]  Cursor          (.cursor/rules)
   771→  [ ]  8)  [ ]  Aider           (CONVENTIONS.md)
   772→  [ ]  9)  [ ]  Windsurf        (.windsurfrules)
   773→  [ ] 10)  [ ]  Qwen Code       (~/.qwen/agents)
   774→  [ ] 11)  [ ]  Kimi Code       (~/.config/kimi/agents)
   775→  [ ] 12)  [ ]  Codex           (~/.codex/agents)
   776→  [ ] 13)  [ ]  Osaurus         (~/.osaurus/skills)
   777→  [ ] 14)  [ ]  Hermes          (~/.hermes/plugins)
   778→
   779→  [1-14] toggle   [a] all   [n] none   [d] detected
   780→  [Enter] install   [q] quit
   781→```
   782→
   783→**Or install a specific tool directly:**
   784→```bash
   785→./scripts/install.sh --tool cursor
   786→./scripts/install.sh --tool opencode
   787→./scripts/install.sh --tool openclaw
   788→./scripts/install.sh --tool antigravity
   789→./scripts/install.sh --tool codex
   790→./scripts/install.sh --tool osaurus
   791→./scripts/install.sh --tool hermes
   792→```
   793→
   794→**Non-interactive (CI/scripts):**
   795→```bash
   796→./scripts/install.sh --no-interactive --tool all
   797→```
   798→
   799→**Faster runs (parallel)** — On multi-core machines, use `--parallel` so each tool is processed in parallel. Output order across tools is non-deterministic. Works with both interactive and non-interactive install: e.g. `./scripts/install.sh --interactive --parallel` (pick tools, then install in parallel) or `./scripts/install.sh --no-interactive --parallel`. Job count defaults to `nproc` (Linux), `sysctl -n hw.ncpu` (macOS), or 4; override with `--jobs N`.
   800→
   801→```bash
   802→./scripts/convert.sh --parallel                    # convert all tools in parallel
   803→./scripts/convert.sh --parallel --jobs 8           # cap parallel jobs
   804→./scripts/install.sh --no-interactive --parallel   # install all detected tools in parallel
   805→./scripts/install.sh --interactive --parallel      # pick tools, then install in parallel
   806→./scripts/install.sh --no-interactive --parallel --jobs 4
   807→```

   969→See [integrations/openclaw/README.md](integrations/openclaw/README.md) for details.
   970→
   971→</details>
   972→
   973→<details>
   974→<summary><strong>Qwen Code</strong></summary>
   975→
   976→SubAgents are installed to `.qwen/agents/` in your project root (project-scoped).
   977→
   978→```bash
   979→# Convert and install (run from your project root)
   980→cd /your/project
   981→./scripts/convert.sh --tool qwen
   982→./scripts/install.sh --tool qwen
   983→```
   984→
   985→**Usage in Qwen Code:**
   986→- Reference by name: `Use the frontend-developer agent to review this component`
   987→- Or let Qwen auto-delegate based on task context
   988→- Manage via `/agents` command in interactive mode
   989→
   990→> 📚 [Qwen SubAgents Docs](https://qwenlm.github.io/qwen-code-docs/en/users/features/sub-agents/)
   991→
   992→</details>
   993→
   994→<details>
   995→<summary><strong>Kimi Code</strong></summary>
   996→
   997→Agents are converted to Kimi Code CLI format (YAML + system prompt) and installed to `~/.config/kimi/agents/`.
   998→
   999→```bash
  1000→# Convert and install
  1001→./scripts/convert.sh --tool kimi
  1002→./scripts/install.sh --tool kimi
  1003→```
  1004→
  1005→**Usage with Kimi Code:**
  1006→```bash
  1007→# Use an agent
  1008→kimi --agent-file ~/.config/kimi/agents/frontend-developer/agent.yaml
  1009→
  1010→# In a project
  1011→kimi --agent-file ~/.config/kimi/agents/frontend-developer/agent.yaml \
  1012→     --work-dir /your/project \
  1013→     "Review this React component"
  1014→```
  1015→
  1016→See [integrations/kimi/README.md](integrations/kimi/README.md) for details.
  1017→
  1018→</details>
  1019→
  1020→<details>
  1021→<summary><strong>Codex</strong></summary>
  1022→
  1023→Each agent is converted into a Codex custom agent TOML file and installed to `~/.codex/agents/`.
  1024→
  1025→```bash
  1026→./scripts/convert.sh --tool codex
  1027→./scripts/install.sh --tool codex
  1028→```
  1029→
  1030→Then reference the custom agent by name in Codex:
  1031→```
  1032→Use the Frontend Developer agent to review this component.
  1033→```
  1034→
  1035→See [integrations/codex/README.md](integrations/codex/README.md) for details.
  1036→</details>
  1037→

  1039→
  1040→### Regenerating After Changes
  1041→
  1042→When you add new agents or edit existing ones, regenerate all integration files:
  1043→
  1044→```bash
  1045→./scripts/convert.sh                    # regenerate all (serial)
  1046→./scripts/convert.sh --parallel         # regenerate all in parallel (faster)
  1047→./scripts/convert.sh --tool codex       # regenerate just one tool
  1048→./scripts/convert.sh --tool cursor      # regenerate just one tool
  1049→```
